3. 권한과 자동기록 선택

  • 위치: GPS로 방문 영역과 경로를 기록하는 데 사용합니다. 세밀한 영역을 구분하려면 정확한 위치가 필요합니다. 화면을 꺼도 기록 이어가기를 켜면 허용된 범위에서 백그라운드에도 위치를 사용합니다. 운전앱 자동화로 앱이 열려 있지 않을 때 기록을 시작하려면 ‘항상 허용’ 권한이 필요할 수 있습니다.
  • 알림: 장시간 정지 등으로 기록이 종료되었음을 기기 내 알림으로 알리는 데 사용합니다. 알림을 위한 별도 서버를 운영하지 않습니다.
  • 집중 모드·운전앱 연동: 사용자가 직접 추가한 집중 모드 필터나 단축어 자동화의 실행 신호를 사용합니다. 다른 앱의 실행 목록, 내비게이션 목적지, 메시지 또는 건강·수면 기록을 읽지 않습니다.

위치 권한을 거절해도 예시 데이터와 기존에 저장된 기록을 둘러볼 수 있습니다. 자동기록·운전앱·워치 연동은 앱 설정에서 끌 수 있으며, 위치와 알림 권한은 iPhone 또는 Apple Watch의 시스템 설정에서 변경할 수 있습니다. 워치가 연결되어 있지 않으면 iPhone의 종료 요청이나 집중 모드 설정 전달이 지연될 수 있으므로 워치에서도 기록 종료를 확인해 주세요.

4. 지도와 외부 서비스

개발자는 위치 기록과 감상 파일을 별도 서버나 광고업체로 전송하지 않습니다. 다만 다음 기능을 사용할 때 해당 서비스와 통신합니다.

지도 표시

앱 설정의 ‘지도 제공’에 표시된 Apple 지도(MapKit) 또는 NAVER 지도를 사용합니다. 지도 화면을 불러오면 지도 제공자가 IP 주소, 요청한 지도 영역, 기기·서비스 요청 관련 정보 등을 처리할 수 있습니다. 현재 위치 표시 기능을 사용하면 위치 정보도 해당 지도 서비스에서 처리될 수 있습니다. 지도 위의 방문 색칠과 감상은 앱이 기기에서 그리며, 저장된 전체 이동 경로 파일이나 감상 내용을 지도 제공자에게 업로드하는 기능은 제공하지 않습니다.

Apple Watch와 동기화

워치 기록을 켜면 연결된 iPhone과 Apple Watch가 Apple의 WatchConnectivity를 통해 위치·시각·카테고리·기록 설정 및 동기화 식별자를 주고받습니다. 연결이 끊기면 워치에 기록을 보관했다가 다시 연결될 때 전송합니다. 개발자의 서버를 거치도록 구현하지 않았습니다.

백업 파일과 운영체제 백업

‘백업 파일 저장’을 선택하면 위치와 이동 경로·감상·설정이 포함된 JSON 파일을 사용자가 지정한 곳에 저장합니다. 이 파일은 앱이 별도 암호화하지 않으므로 보관·공유 대상에 유의해 주세요. iCloud Drive나 다른 클라우드·공유 앱을 선택하면 해당 제공자가 파일을 처리할 수 있습니다. 앱 저장 공간도 사용자의 iCloud·컴퓨터 기기 백업 설정에 따라 백업에 포함될 수 있습니다. 이는 앱이 자체 계정이나 개발자 서버로 제공하는 클라우드 동기화와는 구별됩니다.

외부 서비스가 처리하는 정보의 보관 기간·처리 지역·보호 조치는 해당 제공자의 방침과 사용자 설정에 따릅니다. Apple 및 사용자가 선택한 해외 클라우드 서비스를 이용할 때 정보가 국외에서 처리될 수 있습니다. Apple 개인정보 처리방침에서 관련 내용을 확인할 수 있습니다.

5. 보관 기간과 삭제 방법

iPhone에 저장된 방문 영역·이동 경로·감상은 이용자가 삭제하기 전까지 보관합니다. 일정 기간이 지났다는 이유로 자동 삭제하지 않습니다. 워치의 전송 대기 기록은 iPhone에 최종 저장되었다는 확인을 받은 뒤 워치에서 삭제합니다.

  1. 새 기록 중지: 앱에서 기록을 마치고 자동기록·운전앱·워치 연동을 끄거나 시스템 위치 권한을 해제합니다. 이 조작은 기존 기록을 삭제하지 않습니다. 연결되지 않은 워치는 워치 앱에서도 기록을 종료해 주세요.
  2. 감상 삭제: 기록 탭에서 기억을 길게 누르고 ‘기억 삭제’를 선택합니다. 이 경우 방문 영역과 이동 경로는 남습니다.
  3. 기기 내 전체 기록 삭제: 현재 버전은 앱 안에서 방문 영역·경로를 일괄 삭제하는 기능을 제공하지 않습니다. iPhone의 시스템 설정에서 나의발자취를 ‘앱 삭제’하면 해당 기기의 앱 저장 데이터를 제거할 수 있습니다. ‘앱 정리하기’는 데이터를 보관하므로 전체 삭제 방법에 해당하지 않습니다. 워치에 남은 미전송 기록을 제거하려면 워치 앱도 별도로 삭제해 주세요.
  4. 별도 사본 삭제: 내보낸 JSON 파일, 공유한 사본, iCloud·컴퓨터 기기 백업은 앱 삭제만으로 지워지지 않습니다. 저장한 위치나 해당 서비스의 관리 기능에서 별도로 삭제해야 하며, 과거 백업을 복원하면 이전 기록이 다시 나타날 수 있습니다.

개발자가 보관하는 위치 기록 사본은 없으므로 개발자가 원격으로 기기 데이터를 대신 삭제할 수는 없습니다. 삭제 방법이나 권한 철회에 도움이 필요하면 아래 연락처로 문의할 수 있습니다.
