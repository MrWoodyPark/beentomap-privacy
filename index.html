3. 권한과 자동기록 선택

앱 프로세스가 종료된 뒤 백그라운드에서 다시 실행돼도 이전 아이폰 경로를 자동 재개하지 않습니다. 마지막으로 저장된 위치까지 경로를 종료하고, 이후 사용자가 앱을 열면 새 경로를 시작합니다. iOS가 앱을 종료한 경우에도 같은 원칙을 적용하므로 기록에 공백이 생길 수 있습니다. 사용자가 별도로 연결한 운전앱 자동화와 독립된 워치 기록은 각 설정에 따라 동작합니다.

‘처음 가본 지역에서 앱 실행 알림’은 이용자가 설정 첫 화면에서 켠 경우에만 작동합니다. 앱을 종료한 뒤에도 새 장소 여부를 판단하기 위해 주요 위치 변경 서비스를 통해 위치를 간헐적으로 확인합니다. 위치 ‘항상 허용’·정확한 위치·백그라운드 앱 새로 고침·알림 권한이 필요합니다. 감지한 위치는 방문 영역이나 이동 경로로 저장하지 않으며, 새로운 국내 지역이면 ‘앱을 열고 발자취 기록을 시작할까요?’ 알림만 보냅니다. 이용자가 알림에서 앱을 열거나 직접 앱을 연 뒤에 기록합니다. ‘나중에’를 선택하거나 알림을 닫으면 기록하지 않습니다. 알림 권한이 없어도 감지만으로 기록을 시작하지 않습니다. 강제 종료 후에도 iOS가 앱을 깨워 알림을 보낼 수 있지만 감지·알림의 즉시성이나 매번 전달을 보장하지 않습니다.

감지 설정, 비교 기준 위치·시각, 마지막 알림 시각(구버전의 마지막 자동 시작 시각도 호환 목적으로 보관), 자동기록 제외 격자·이름은 기기에 보관하고 백업에 포함합니다. 새 지역 판별과 반복 알림 제한·지정 영역의 기록 제외에 사용합니다. 자동기록 제외 영역을 지나가는 위치는 통과 판단에 사용하지만 새 자동기록에 저장하지 않습니다. 기존 기록은 유지하며 수동·워치 기록에는 제외 설정을 적용하지 않습니다.

  • 위치: 처음 실행한 지도의 현재 위치 표시와, 이용자가 시작한 방문 영역·경로 기록에 사용합니다. 세밀한 영역을 구분하려면 정확한 위치가 필요합니다. 기록이 시작되면 별도의 백그라운드 스위치 없이 허용된 범위에서 화면을 꺼도 위치를 사용합니다. 운전앱 자동화는 앱 화면 열기를 요청하며, 앱이 열린 뒤 일반 실행과 같은 기본 기록을 적용합니다. iOS가 확인 또는 잠금 해제를 요구할 수 있습니다.
  • 알림: 장시간 정지 등으로 기록이 종료되었음을 기기 내 알림으로 알리는 데 사용합니다. 알림을 위한 별도 서버를 운영하지 않습니다.
  • 운전앱 연동: 사용자가 직접 연결한 단축어 자동화의 실행 신호를 사용합니다. 수면·집중 모드 필터 연동은 제거했습니다. 다른 앱의 실행 목록, 내비게이션 목적지, 메시지 또는 건강·수면 기록을 읽지 않습니다.

위치 권한을 거절해도 예시 데이터와 기존에 저장된 기록을 둘러볼 수 있습니다. 진행 중인 기록은 지도에서 마칠 수 있고 처음 가본 지역에서 앱 실행 알림·운전앱·워치 연동은 설정 첫 화면에서 끌 수 있으며, 위치와 알림 권한은 iPhone 또는 Apple Watch의 시스템 설정에서 변경할 수 있습니다. 워치가 연결되어 있지 않으면 iPhone의 종료 요청 전달이 지연될 수 있으므로 워치에서도 기록 종료를 확인해 주세요.

4. 지도와 외부 서비스

개발자는 위치 기록과 감상 파일을 별도 서버나 광고업체로 전송하지 않습니다. 다만 다음 기능을 사용할 때 해당 서비스와 통신합니다.

지도 표시

Apple 지도(MapKit)를 사용합니다. NAVER 지도 SDK는 현재 버전에서 제거했습니다. 지도 화면을 불러오면 지도 제공자가 IP 주소, 요청한 지도 영역, 기기·서비스 요청 관련 정보 등을 처리할 수 있습니다. 현재 위치 표시 기능을 사용하면 위치 정보도 해당 지도 서비스에서 처리될 수 있습니다. 지도 위의 방문 색칠은 앱이 기기에서 그리며, 저장된 전체 이동 경로 파일이나 감상 내용을 지도 제공자에게 업로드하는 기능은 제공하지 않습니다.

Apple 지도 및 개인정보 보호

장소 검색과 저장한 핀

Apple MapKit 검색에 검색어와 검색 기준 지도 영역을 전달합니다. 앱은 검색어 이력을 저장하지 않습니다. 이용자가 저장한 핀 이름·주소·좌표·저장 시각·핀 분류와, 영역 핀의 선택한 격자 좌표는 기기에 보관하며 방문 통계와 분리합니다. 핀 분류는 음식점·카페·아름다운 경관·개인적으로 기억하고 싶은 장소·런닝하기 좋은 코스·산책하기 좋은 코스입니다. 영역 좌표는 테두리를 그리기 위한 별도 사본이므로 경로를 삭제해도 핀에는 남을 수 있습니다. 핀 수정·삭제 또는 전체 발자취 삭제로 관리할 수 있으며 백업 파일에 포함됩니다.

Apple Watch와 동기화

워치 기록을 켜면 연결된 iPhone과 Apple Watch가 Apple의 WatchConnectivity를 통해 위치·시각·카테고리·기록 설정 및 동기화 식별자를 주고받습니다. 연결이 끊기면 워치에 기록을 보관했다가 다시 연결될 때 전송합니다. 개발자의 서버를 거치도록 구현하지 않았습니다.

백업 파일과 운영체제 백업

‘백업 파일 저장’을 선택하면 위치와 이동 경로·감상·설정이 포함된 JSON 파일을 사용자가 지정한 곳에 저장합니다. 이 파일은 앱이 별도 암호화하지 않으므로 보관·공유 대상에 유의해 주세요. iCloud Drive나 다른 클라우드·공유 앱을 선택하면 해당 제공자가 파일을 처리할 수 있습니다. 앱 저장 공간도 사용자의 iCloud·컴퓨터 기기 백업 설정에 따라 백업에 포함될 수 있습니다. 이는 앱이 자체 계정이나 개발자 서버로 제공하는 클라우드 동기화와는 구별됩니다.

외부 서비스가 처리하는 정보의 보관 기간·처리 지역·보호 조치는 해당 제공자의 방침과 사용자 설정에 따릅니다. Apple 및 사용자가 선택한 해외 클라우드 서비스를 이용할 때 정보가 국외에서 처리될 수 있습니다. Apple 개인정보 처리방침에서 관련 내용을 확인할 수 있습니다.

5. 보관 기간과 삭제 방법

핀은 지도 검색 화면의 핀 보관함이나 지도에서 핀을 선택한 뒤 수정 화면에서 개별 삭제할 수 있습니다. 핀 삭제는 방문 색칠을 삭제하지 않습니다. 자동기록 제외 영역은 설정에서 해제합니다. 전체 발자취 삭제 전에는 처음 가본 지역에서 앱 실행 알림도 꺼 주세요. 전체 삭제는 저장한 핀·제외 영역·감지 기준 위치와 마지막 알림·시작 시각도 지웁니다. 백업을 복원하면 저장한 핀은 복원되지만 새 지역 감지는 꺼지고 감지 기준 위치·시각은 초기화됩니다.

iPhone에 저장된 방문 영역·이동 경로·감상은 이용자가 삭제하기 전까지 보관합니다. 일정 기간이 지났다는 이유로 자동 삭제하지 않습니다. 워치의 전송 대기 기록은 iPhone에 최종 저장되었다는 확인을 받은 뒤 워치에서 삭제합니다.

  1. 새 기록 중지: 지도에서 기록을 마치고 설정 첫 화면의 처음 가본 지역에서 앱 실행 알림·운전앱·워치 연동을 끄거나 시스템 위치 권한을 해제합니다. 이 조작은 기존 기록을 삭제하지 않습니다. 연결되지 않은 워치는 워치 앱에서도 기록을 종료해 주세요.
  2. 이전 감상: 새 버전에서는 감상 화면을 제공하지 않습니다. 기존 감상은 백업에 포함되며, 전체 발자취 삭제 시 함께 삭제됩니다.
  3. 기기 내 전체 기록 삭제: 아이폰 자동기록과 워치 기록 사용을 끈 뒤 설정의 ‘전체 발자취 삭제’를 선택하면 방문 영역·이동 경로·감상을 모두 삭제합니다. 카테고리는 유지하며 운전앱 자동기록 연동은 꺼집니다. 이전 연결의 워치 기록은 다시 가져오지 않도록 연결 식별자를 변경합니다. 개별 경로는 설정의 이동 경로 관리를 길게 눌러 삭제할 수 있으며, 연결된 기억과 해당 경로로만 방문한 영역을 함께 삭제합니다. 다른 경로와 겹치는 영역은 보존하고 방문 날짜·농도를 다시 계산합니다. 삭제한 워치 경로의 재전송을 차단하기 위해 경로 내용이 없는 세션 식별자를 기기에 보관하며, 전체 기록 삭제 시 제거합니다. iPhone의 시스템 설정에서 나의발자취를 ‘앱 삭제’해도 해당 기기의 앱 저장 데이터를 제거할 수 있습니다. ‘앱 정리하기’는 데이터를 보관하므로 전체 삭제 방법에 해당하지 않습니다. 워치에 남은 미전송 기록을 제거하려면 워치 앱도 별도로 삭제해 주세요.
  4. 별도 사본 삭제: 내보낸 JSON 파일, 공유한 사본, iCloud·컴퓨터 기기 백업은 앱 삭제만으로 지워지지 않습니다. 저장한 위치나 해당 서비스의 관리 기능에서 별도로 삭제해야 하며, 과거 백업을 복원하면 이전 기록이 다시 나타날 수 있습니다.
